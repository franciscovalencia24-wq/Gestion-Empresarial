1. Stack Tecnológico Base (Core)

El sistema está construido bajo una arquitectura modular en Python, diseñada para alta escalabilidad, procesamiento concurrente y seguridad de datos bancarios.
Capa del Sistema Tecnología / Framework Propósito en la Plataforma
Frontend / UI Streamlit / HTML5 / CSS3 Interfaces interactivas para gestión de cartolas, CRM y cuadros de mando.
Backend & Lógica Python 3.10+ Orquestación de agentes, procesamiento de datos y scripts de extracción.
Base de Datos SQLite 3 / SQLAlchemy Almacenamiento encriptado local (`database.db`, `prospectos.db`) para máxima privacidad sin nube externa.
Inteligencia Artificial Google Gemini / OpenAI LLMs Motores de lenguaje natural para lectura óptica (OCR) y razonamiento complejo.
Extracción / OSINT PyPDF2, Regex, Selenium Scraping de datos públicos (CMF, CAMV) y lectura de cartolas financieras.

2. Clúster de Agentes Inteligentes (Intelligence)

Supervisor / Orchestrator Agent src/intelligence/supervisor.py
Producción

El nodo central de jerarquía. Evalúa la complejidad de cada tarea ingresada al ecosistema y la delega al agente especializado correspondiente. Monitorea que todos los sub-agentes cumplan sus objetivos sin alucinaciones.

Task Delegation Agentic Routing
Proactive Advisor src/intelligence/proactive_advisor.py
Producción

Actúa como el consejero principal que analiza los portafolios y detona alertas proactivas. Utiliza técnicas de recuperación aumentada (RAG) para aconsejar basándose en el historial del cliente.

LangChain LLM Reasoning RAG
Data Scientist Agent src/intelligence/data_scientist.py
Producción

Especialista en análisis estadístico. Procesa grandes volúmenes de datos numéricos provenientes de cartolas y series históricas, ejecutando las simulaciones Monte Carlo y pruebas de estrés institucionales.

Pandas/NumPy Monte Carlo
Market Analyst Agent src/intelligence/market_analyst.py
Producción

Rastrea tendencias macroeconómicas globales. Digiere noticias financieras, tasas de interés de bancos centrales y fluctuaciones de commodities para contextualizar los riesgos de los portafolios de nuestros clientes.

Macroeconomics Time Series Analysis
Technical Analyst & Quant Agent src/agents/technical_analyst.py
Producción

Agente algorítmico especializado en análisis técnico institucional. Calcula osciladores de momento (RSI, MACD), tendencias (SMA 20/50/200) y bandas de volatilidad en tiempo real sobre datos de la Bolsa de Santiago y EE.UU. Su núcleo de IA genera dictámenes matemáticos instantáneos.

yfinance API Pandas-TA Plotly Interactive Gemini Quant
Competitor Agent src/intelligence/competitor_agent.py
Producción

Agente entrenado específicamente para leer folletos, fondos mutuos y propuestas de bancos competidores. Extrae costos ocultos, comisiones fantasmas y elabora cuadros comparativos matemáticos para desarmar la oferta rival.

OCR Avanzado NLP Finance
Execution Agent src/intelligence/execution_agent.py
Fase Beta

Encargado de llevar a la acción las estrategias diseñadas. Formatea órdenes, compila los informes finales en PDF y dispara las notificaciones al equipo humano para el contacto final con el cliente.

Workflow Automation Report Generation
LLM Reader Agent src/osint/llm_reader.py
Producción

Módulo de visión por computadora y extracción de texto profundo. Es capaz de "leer" contratos, pólizas escaneadas y extraer cláusulas abusivas que los sistemas OCR tradicionales omiten.

Producción

Motor de ingesta automatizada. Lee archivos PDF bancarios, reconoce tablas de inversiones de distintas instituciones y consolida el patrimonio en un formato estandarizado dentro de la base de datos.

Scraper CMF y CAMV src/osint/scraper_cmf.py
Producción

Robots de Inteligencia de Fuentes Abiertas (OSINT). Se conectan diariamente a la Comisión para el Mercado Financiero y al CAMV para descargar series históricas, valores cuota y certificar datos de mercado sin intervención humana.

Web Scraping Data Mining
